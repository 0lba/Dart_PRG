## Ответы на вопросы
1. Абстрактный класс - это класс, который существует только как шаблон для наследников. Написать Character() напрямую нельзя, потому что это абстрактный класс. В нем есть абстрактный метод attack(), у которого нет тела. Если бы можно было создать объект Character, программа не знала бы, какой именно код должен выполняться при вызове attack().
2. super - это ссылка на родительский класс. В конструкторе наследника вызов super(name: name, hp: 120) необходим для того, чтобы передать данные в конструктор родителя и инициализировать его поля. Если его убрать, родительский класс не будет инициализирован.
3. attack() в родительском классе Character объявлен как абстрактный метод . Наследник обязан его реализовать, чтобы задать уникальный урон для каждого класса. takeDamage() в родителе уже имеет реализацию. В классе Warrior этот метод переопределяется, чтобы добавить специфику - учет брони. takeDamage - метод родителя с уменьшенным уроном». То есть, @override здесь используется, чтобы изменить поведение уже существующего метода, добавив новую логику, но не переписывая базовую с нуля.
4. Эта концепция называется полиморфизм. Во Flutter мы это видели в работе с виджетами.
5. Нижнее подчеркивание _ в Dart означает, что переменная является приватной.
